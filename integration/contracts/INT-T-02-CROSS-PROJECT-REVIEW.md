# INT-T-02 — مراجعة توافق D-09 / ACK·STATE عبر المشاريع

| الحقل | القيمة |
|--------|--------|
| التاريخ | 2026-11-22 |
| النطاق | توثيق D-09 وأمثلة الترتيب وقواعد `device_states` — **ليس** اعتماد G1 |
| المراجِعون | مراجعة تقنية AI من منظور Backend / ESP / Flutter (بديل توثيقي؛ الاعتماد الثلاثي البشري = INT-T-04) |
| الوثيقة الأم | [`D-09-COMMAND-ACK-AND-STATE.md`](./D-09-COMMAND-ACK-AND-STATE.md) |

## الحكم الإجمالي

**`APPROVE_WITH_GAPS`** ضمن نطاق INT-T-02 (توثيق + أمثلة + توافق مع التنفيذ الحالي).  
الفجوات أدناه **لا تمنع** إغلاق INT-T-02 كوثيقة؛ تمنع إعلان G1 / إنتاج.

---

## Backend

| بند | التقييم | دليل |
|-----|---------|------|
| D-09 لقطة كاملة + `resultStateSequence` | متوافق | `ParseCommandAck` · مخطط `command-ack.schema.json` |
| عدم رجوع التسلسل | متوافق | `sequence <= stored` → ignore / `COMMAND_CLOSED_ONLY` |
| ACK يغلق الأمر دون اشتراط STATE مسبق | متوافق | مسار ACK المستقل |
| LATE_ACK بعد TIMED_OUT | متوافق | `DeviceCommandLifecycleTests.Late_Ack_After_Timeout_*` |
| غياب حقول ACK الاختيارية | متوافق | لا رفع ملكية/لا مسح ثقة بلا حقل |
| HTTP/PUBACK ليسا تنفيذاً | متوافق | تعليقات الخدمة + `actualStateChanged=false` |
| MQTT إنتاجي | معطّل عمداً | `appsettings.json` |

**فجوات مؤجّلة:** `MutedAt` (BE-T-05)؛ إثبات broker حي لترتيب ACK/STATE على المسار الإنتاجي (G1).

## ESP

| بند | التقييم | دليل |
|-----|---------|------|
| توقع ACK كامل في المسودة | متوافق عقدياً | MQTT-V1-DRAFT · G1-CD |
| رفض أمر بلا وقت موثوق | مبدأ معتمد | FR-017 · G1-CD-5 |
| استمرار `stateSequence` | مبدأ؛ إثبات عتاد معلّق | D-05 / DEP-HW-05 |
| firmware يرسل الترتيب S01…S08 | غير مثبت على عتاد | خارج INT-T-02 |

**فجوات مؤجّلة:** عتاد D-01؛ قطع طاقة؛ ناشر `DEVICE_FAULT`.

## Flutter (Mobile/Web)

| بند | التقييم | دليل |
|-----|---------|------|
| لا MQTT مباشر | متوافق | AGENTS / خطط العميل |
| عدم استنتاج تنفيذ من 202 | متوافق مع قواعد العرض المعتمدة | حراس أوامر / تقارير سابقة |
| عرض S1 / healthCode | فجوة UX موثّقة | DEP-FLUT-01 |

**فجوات مؤجّلة:** تشغيل جهاز/محاكٍ؛ parity حراس Mobile (DEP-FLUT-02).

## توصية للمالك

قبول توثيق INT-T-02 كامتداد مسودة D-09 **دون** إغلاق G1. الاعتماد النهائي عند INT-T-04 بعد الأدلة.
