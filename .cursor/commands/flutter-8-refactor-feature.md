# Refactor Feature

Improve the implementation without changing functionality.

## Instructions

1. Inspect the feature.
2. Identify improvement opportunities.
3. Use the Refactor Feature Skill (`.cursor/skills/flutter-refactor-feature/SKILL.md`).
4. Apply the smallest safe changes.
5. Validate the feature.
