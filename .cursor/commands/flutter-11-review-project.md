# Review Project

Review the complete project.

Use the project's architecture, Rules, and the Review Project Skill.

## Instructions

1. Inspect the entire codebase (`lib/features/` and `lib/core/`).

2. Use the Review Project Skill (`.cursor/skills/flutter-review-project/SKILL.md`).

3. Apply `flutter-senior-engineer` Definition of Done across features.

4. Detect architectural inconsistencies and duplicated infrastructure.

5. Prioritize project-wide issues.

6. Generate the final report.

Do not rewrite code unless requested.

## Expected Result

A complete project assessment with prioritized improvements.
