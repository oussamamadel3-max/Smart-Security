# Create Feature

Create a new production-ready Flutter feature.

Use the project's architecture, Rules, Skills and Templates.

## Instructions

1. Inspect the existing project.

2. Determine the minimum required information.

3. Ask only for missing information.

4. Use the Create Feature Skill (`.cursor/skills/flutter-create-feature/SKILL.md`).

5. Generate only the necessary files.

6. Reuse existing infrastructure.

7. Validate the generated feature against the project Rules and `flutter-senior-engineer`. Use Riverpod **or** BLoC per `.cursor/docs/flutter/stack.md` / existing code — never both.

## Expected Result

A complete feature integrated into the project without architecture violations.
