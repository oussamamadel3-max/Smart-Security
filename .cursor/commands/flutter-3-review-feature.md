# Review Feature

Review a Flutter feature.

Use the project's architecture, Rules, and the Review Feature Skill.

## Instructions

1. Inspect the feature.

2. Use the Review Feature Skill (`.cursor/skills/flutter-review-feature/SKILL.md`).

3. Apply `flutter-senior-engineer` Definition of Done and the eight invariants.

4. Identify architecture violations.

5. Prioritize findings.

6. Suggest the smallest safe improvements.

Do not rewrite code unless requested.

## Expected Result

A structured engineering review with actionable recommendations.
