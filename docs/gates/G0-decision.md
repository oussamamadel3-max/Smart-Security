## إضافة مالك 2026-11-21 — تثبيت قرارات دون إغلاق البوابة

وُافق المالك على تثبيت الحالات التالية **دون** `APPROVE TASK CLOSURE: ESP-T-01` / `G0` ودون اعتبار النظام جاهزاً للإنتاج:

| البند | الحالة المعتمدة من المالك |
|-------|---------------------------|
| D-01 قطع إلكترونية نهائية | `DEFERRED — HARDWARE DECISION PENDING` — BOM أولي غير معتمد للشراء/الإنتاج؛ لا إعادة تصميم Firmware بسبب التأجيل |
| D-02 قاعدة تحقق الاهتزاز | `OWNER APPROVED — HARDWARE CALIBRATION PENDING` — الأرقام `TEST_ONLY` |
| D-03 / NFR-008 | `PROVISIONAL DEVELOPMENT VALUES — PRODUCTION VALIDATION PENDING` — فصل ACK Timeout عن Command TTL |
| D-04 تدوير الاعتماد v1 | `OWNER APPROVED — MANUAL ROTATION FOR V1` |
| سياسة سلامة تلف الإعداد / فقد الطاقة | `OWNER APPROVED — S1 — VALIDATION PENDING` |
| D-05…D-09 | قرارات سابقة نافذة بلا إعادة فتح |
| MQTT/TLS | تكامل محلي معزول مسموح؛ الإنتاج معطّل؛ لا استثناء TLS إنتاجي |

**ما لم يتغير:** `ESP-T-01` تبقى `[ ]` · العدّاد الرسمي ESP `0/9` · لا firmware إنتاج.

## لماذا NOT CLOSED

1. لا موافقة إغلاق بالصيغة المعتمدة (`APPROVE TASK CLOSURE: ESP-T-01` أو `APPROVE TASK CLOSURE: G0`).
2. D-01 مؤجّل للاعتماد النهائي للقطع؛ لا شراء نهائي ولا قياس تيار/سلامة 12V مكتمل.
3. معايرة D-02 وقياس D-03/D-05 وتحقق S1 معلّقة على عتاد حقيقي.
4. اعتماد مبدأ منتج أو إجراء v1 لا يعني اكتمال التحقق العتادي لإغلاق البوابة.

## ما تم توثيقياً سابقاً (2026-11-18) — بلا تغيير تاريخي

- سجل قرارات D-01…D-07، BOM أولي، مخطط توصيل نصي، خطة معايرة SW-420، إعلان مسموح/محظور.
- ذلك يبقى مسودة مراجعة؛ قرارات 2026-11-21 حدّثت **الحالات الرسمية** في سجل العتاد دون إغلاق G0.

## مسموح / محظور قبل الإغلاق

**مسموح:** تجارب طاولة منخفضة الجهد؛ بناء ESP-IDF؛ منطق حماية بمحفز اصطناعي؛ أعمال برمجية مستقلة بلا firmware إنتاج؛ تكامل محلي معزول وفق سياسة MQTT المعتمدة.

**محظور:** firmware إنتاج؛ تشغيل دائرة 12V كاملة بلا سجل سلامة T-02؛ تثبيت قيم TTL/سعة/معايرة إنتاجية؛ تفعيل Secure Boot/Flash Encryption غير القابل للعكس؛ اعتبار BOM شراءً نهائياً.

## أصغر خطوات قبل READY FOR APPROVAL / الإغلاق

1. استكمال اعتماد D-01 النهائي عند جاهزية القطع (رفع التأجيل بقرار مالك لاحق).
2. ESP-T-02: قياس تيار + سجل سلامة 12V.
3. معايرة D-02 وتوثيق الأرقام؛ قياس D-03/NFR-008؛ إثبات D-05 وS1 على عتاد.
4. بعدها فقط: طلب `APPROVE TASK CLOSURE: ESP-T-01` / `G0`. الإغلاق الذاتي **لا ينطبق** على T-01/G0 (`AGENTS.md`).

إلى أن يحدث ذلك يبقى القرار `G0 NOT CLOSED`.
