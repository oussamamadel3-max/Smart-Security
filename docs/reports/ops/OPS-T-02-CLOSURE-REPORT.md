## 1. نطاق الإغلاق الرسمي

أُغلق **OPS-T-02 فقط** ضمن:

- OPS-01 بيئات منفصلة (قوالب development/staging/production)
- OPS-03 أسرار وTLS وجدار ناري (وثائق + قوالب شبكة)
- قائمة تحقق عدم تسريب الأسرار + سكربت آلي
- سياسة JWT لكل بيئة + تدوير/إبطال/استرجاع موثّقة
- CORS/Cookie/CSRF/Origin لكل بيئة + **تجهيز** اختبار HTTPS

**خارج نطاق هذا الإغلاق:** نشر staging حي · تفعيل MQTT/Outbox إنتاجي · تنفيذ HTTPS حي · تدوير JWT متعدد المفاتيح دون انقطاع في Backend · G0/G1/G2 · OPS-T-03 · INT-T-04.

### تأجيل HTTPS الحي — لا يخالف البطاقة

نص البطاقة الفرعية: «…وتجهيز اختبارها على HTTPS فعلي».  
شرط القبول يطلب التحقق من **صلاحية إعدادات الويب لكل بيئة** — تم عبر القوالب و`Test-EnvIsolationDocs`.  
تنفيذ الاختبار على مضيف HTTPS حي **ليس** شرطاً إلزامياً لـ T-02 عند غياب المضيف؛ يبقى ضمن **OPS-T-03**.
