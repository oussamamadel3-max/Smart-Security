## المشاكل غير المعالجة وأسبابها

- `WEB-EXT-01`…`WEB-EXT-07`: تحتاج Backend أو جهازًا أو FCM أو متصفحًا ضد API حقيقي. التفويض يمنع اختراع النجاح ويمنع تعديل المشاريع الأخرى.
- `WEB-EXT-08`: لقطة الدخول من النسخة المبنية وثقّت فرق النموذج التجريبي. تفاصيل المالك والسجل والشريط العريض والدرجات 360…1920 بلا لقطة متصفح من `build/web`. الصف الممتلئ في سجل المالك عند ≥900 لم يُضخ بمعرّف طويل (الحكم `PARTIAL` منذ C-05). القص في `_DataRow` موجود؛ لا اختبار جديد لأن القبول الحرج مغطى.
- بناء release الافتراضي يبقى بيئة `dev`. نشر الإنتاج يحتاج تعريفًا صريحًا لـ `APP_ENV` و`API_BASE_URL`، ولم يُطلب هنا.
- 23 حزمة أحدث خارج قيود `pubspec` لم تُرفع.
- تحذير Wasm dry run لا يعني بناء `--wasm`.

## التحسينات المعمارية

اتجاه Presentation → Domain ← Data بقي. إنشاء الأمر واستعلام حالته يمران بـ UseCase. مزودات العرض ما زالت جذر التركيب الذي يستورد التنفيذ، وهو مقبول في C-01 بلا إعادة هيكلة واسعة. `SessionEpoch` يمنع تطبيق نتيجة طلب بعد إبطال الجلسة دون تحويل كل المزودات إلى `autoDispose` حتى لا يسقط حاجز `TIMED_OUT`.

## التحسينات الأمنية

Access يبقى في `AccessTokenHolder` داخل الذاكرة. لا `localStorage` / `sessionStorage` للرموز. 403 لا يجدّد الجلسة ولا يُنهيها. POST بلا مفتاح عدم تكرار لا يُعاد بعد 401. الكاش لا يُعاد ملؤه إذا تغيّر عصر الجلسة أثناء الطلب. الحارس ما زال تجربة مستخدم والخادم سلطة التفويض. الكوكي الحي وCSRF/Origin ضد Backend **NOT VERIFIED**.

## تحسينات الواجهات وتجربة الاستخدام

عربي RTL، دخول بعرض المرجع وحقول فارغة، شبكة أجهزة، بطاقات حالة، لوحة أوامر المالك، غلاف أدمن موحّد، تحقق على الحقل، حوار تأكيد، حالات تحميل/فراغ/خطأ موجودة من قبل، شريط انتهاء الجلسة، صفحة مسار غير معروف، وتحذير مغادرة نماذج الإنشاء. لا هيكل عظمي جديد للتحميل.
