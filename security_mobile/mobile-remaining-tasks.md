# الأعمال المتبقية خارج الاستكمال البرمجي (Software-Only)

ملف مستقل — **لا** يُحسب ضمن إجمالي مهام النظام (50).  
يمثّل ما تعذّر إكماله إنتاجياً في مرحلة MOB-C-01…C-06 بسبب اعتماديات خارج `security_mobile`.

| # | العمل | السبب / الاعتماد | شرط القبول المستقبلي |
|---|--------|------------------|----------------------|
| R-01 | تهيئة Firebase Apps + APNs لكل flavor | لا ملفات عميل · سياسة عدم بدء تكامل Firebase الآن | ملفات `google-services` / `GoogleService-Info` لكل بيئة + اختبار استقبال رسالة |
| R-02 | استبدال `NoOpFcmMessaging` بتنفيذ SDK حي | يعتمد R-01 | token حقيقي · onTokenRefresh · إذن OS على جهاز |
| R-03 | fg/bg/terminated + رسالة اختبار | جهاز Android حقيقي | دليل ميداني موثّق |
| R-04 | بناء/اختبار iOS | مؤجّل بموافقة المالك | بناء iOS + APNs |
| R-05 | soft-AP Wi-Fi فعلي بدل `UnavailableLocalProvisioningClient` | ESP-T-08 + إغلاق D-04 | عقد HTTP محلي + connected/failed/timeout من الجهاز |
| R-06 | استمرار الإنذار المحلي أثناء تغيير الشبكة | عتاد ESP | اختبار ميداني |
| R-07 | اختبار ACK/STATE وترتيب الرسائل | اعتماد **G1** | عقد معتمد + اختبارات ترتيب |
| R-08 | هاتفان / نقل ملكية متصل حيّ | Backend+جهاز+G1 | سيناريو قبول ميداني |
| R-09 | Server-side Pagination للسجلات | تعديل Backend/عقد — ممنوع في هذه المرحلة | query params معتمدة في integration |
| R-10 | تشغيل APK على جهاز/محاكٍ | ممنوع في قيود الاستكمال | إقلاع يدوي موثّق |
| R-11 | مطابقة بصرية pixel-perfect لـ `design/index.html` | لا لقطات مقارنة في البيئة | screenshots جنب-إلى-جنب عند توفر بيئة عرض |

## تمييز صريح

| المفهوم | الحالة بعد MOB-C-* |
|---------|---------------------|
| اكتمال تنفيذ العميل البرمجي الممكن بدون Firebase/ESP/G1/جهاز | **مكتمل** (C-01…C-06) |
| القبول الإنتاجي الكامل لـ MOB-T-01…T-08 + ميداني | **غير مكتمل** — انظر الجدول أعلاه |
