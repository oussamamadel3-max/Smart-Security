## السياق

- مجلد `admin_web` فارغ من كود التطبيق؛ ملفات التخطيط فقط.
- الويب يشمل شاشات المالك ولوحة الأدمن؛ لا MQTT من المتصفح ولا مسار Wi-Fi محلي معتاد.
- FCM ومسار الهاتف في `security_mobile`؛ الباك إند في `security_backEnd`.
- مصادقة Backend T-02 متاحة وفق تقرير Cursor، لكن ربطها بواجهة الويب ضمن WEB-T-02 لاحقاً؛ لم يُعتمد عقد OpenAPI المشترك لكل المسارات بعد.
- حراسة T-01 **هيكلية فقط**: لا تُعتبر تسجيل دخول حقيقياً أو حماية API أو تفويض أدوار حتى تنفيذ WEB-T-02 والتحقق من الخادم.

## المطلوب

1. إنشاء مشروع Flutter Web داخل `admin_web`.
2. اتجاه عربي RTL، توجيه أولي، هيكل `core` / `features` مع فصل واضح لمساري المالك والأدمن.
3. بيئات dev / staging / prod بلا خلط اعتمادات وبلا أسرار إنتاج في Git.
4. حراسة مسارات أولية: غير المصادق → شاشة الدخول، دون الاعتماد على حالة جلسة وهمية كدليل أمني؛ تُستكمل مصادقة API والتجديد في T-02.
5. `flutter analyze` نظيف للهيكل؛ التطبيق يقلع في المتصفح.

## غير مطلوب في هذه المهمة
